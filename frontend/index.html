⚙️ Core Machine Learning Principles

  • No Hardcoded Rules: HTTPS is NOT treated as safe proof; unusual TLDs are NOT automatically labeled malicious.
  • Zero Data Leakage: Preprocessing pipelines are fit strictly on the training partition (70%) and applied to test and real-time inputs.
  • Multi-Model Rigor: Logistic Regression, Random Forest, and XGBoost are compared under identical stratified splits.
  • Explainability First: Predictions are accompanied by mathematical feature attributions explaining why a risk score was assigned.

🔒 Security, Privacy & Ethical Constraints

  • Zero Code Execution: URL inspection only performs safe HEAD requests without executing JavaScript or downloading binaries.
  • Strict Timeouts: All external network probes have an isolated 2.5-second timeout and default to safe offline values.
  • Privacy Preserving: No user passwords, authentication credentials, or sensitive query strings are permanently stored.
  • Cautious Advisory: System results are explicitly framed as probabilistic ML risk assessments rather than definitive guarantees.
